## 🚀 YOUR DEPLOYMENT - ONLY 2 STEPS NOW!

### STEP 1: Deploy Backend to Railway (5 minutes)

**Open this link:**
https://railway.app

**Do this:**
1. Sign in with your GitHub account (NINJAHATTORI004)
2. Click "New Project"
3. Select "Deploy from GitHub repo"
4. Choose: `NINJAHATTORI004/Taskflow`
5. Set "Root Directory" to: `server`
6. Click "Deploy"

**Add Environment Variables in Railway:**
```
MONGO_URI
mongodb+srv://taskflow:taskflow@cluster0.qhcqyyq.mongodb.net/team-task-manager?appName=Cluster0

JWT_SECRET
taskflow_jwt_secret_2026_secure_key

NODE_ENV
production

PORT
5000
```

**After deployment:**
- Copy your Railway URL (looks like: https://team-task-manager-prod.up.railway.app)
- **Save this URL!** You need it for Step 2

### STEP 2: Deploy Frontend to Vercel (5 minutes)

**Open this link:**
https://vercel.com

**Do this:**
1. Sign in with your GitHub account (NINJAHATTORI004)
2. Click "Add New" → "Project"
3. Click "Import Git Repository"
4. Search: `Taskflow`
5. Click "Import"
6. Set "Root Directory" to: `./client-vite`
7. Add Environment Variable:

```
VITE_API_URL
https://YOUR_RAILWAY_URL/api

(Replace YOUR_RAILWAY_URL with the URL you got from Step 1)
Example: https://team-task-manager-prod.up.railway.app/api
```

8. Click "Deploy"

**After deployment:**
- You'll get a Vercel URL (your live app!)
- **This is your application URL!**
- Share this with your team

- Clear browser cache if needed

- Check cluster is accessible
- Verify database name is correct
